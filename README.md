# Bloodpoint
BloodPoint is an Android-based blood donation management application developed to simplify and improve the process of managing blood donors and their information.The application is developed using Java and XML in Android Studio, with SQLite used as the local database for storing user and donor information.
The system provides a registration and login module through which users can securely access the application. After successful login, users are directed to the main dashboard, where they can access important features of the application.
The Add Donor module allows users to enter essential donor information such as name, mobile number, blood group, and address. The View Donor module displays the stored donor records in an organized list format. Users can also edit or delete donor information whenever required. Database operations such as insertion, retrieval, updating, and deletion are handled through the DBHelper class.
BloodPoint uses separate Java classes for authentication, donor management, database operations, data models, and RecyclerView-based donor display. This modular structure makes the application easier to understand, maintain, and extend.
The system helps reduce manual record management and provides faster access to donor information. In the future, the application can be enhanced with features such as location-based donor or hospital search, notifications, online database synchronization, emergency blood requests, and map integration.
Overall, BloodPoint demonstrates how Android technologies and database management can be combined to create a practical solution for improving blood donation and donor information management.
